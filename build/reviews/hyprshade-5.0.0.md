# hyprshade 5.0.0-1, any

- Provenance:
  - The recipe builds from PyPI's sdist `hyprshade-5.0.0.tar.gz`; its sha256
    equals the recipe's
    (`4a102c34f1be16f34d7c6271051f298e1b8929f2e6d40e06c5d450bad7439efc`).
  - Every file the sdist shares with upstream tag `5.0.0` (commit
    `5195f8b84bf8fead4aa39c47785fc85b87a5746e`, 2026-06-07, unsigned) is
    identical; the sdist lacks only development files (`.github`, lock files,
    `scripts/`, `examples/`) and adds `PKG-INFO`.
  - `examples/config.toml`, the recipe's second source, matches the file at
    that tag (sha256
    `411517f06dc484fb8aad729d73d66cb5b91982ac0c5908184ec9343974392f0a`).
- The local PKGBUILD is the AUR recipe at `89c7100` (2026-06-07), unchanged:
  a wheel built with `python -m build --no-isolation` and installed; the
  shell completions are generated by running the built package.
- Capabilities (933 lines of Python):
  - Sets and clears Hyprland's screen shader with
    `hyprctl eval 'hl.config({ decoration = { screen_shader = '...' } })'`
    (Lua syntax, the path escaped with `lua_escape_str`) and reads it with
    `hyprctl -j getoption`. Ships the shaders blue-light-filter and vibrance.
  - `hyprshade install` writes `hyprshade.service` and `hyprshade.timer` into
    the person's `~/.config/systemd/user`, which outlive any rice. Neither
    rice that needs it runs `install`: degra02 starts `hyprshade on
    vibrance`, hyprdots `hyprshade auto` (checked 2026-09-30).
  - No network, no privilege, no other writes.
- Dependencies: hyprland, python-click, python-more-itertools, util-linux --
  all in Arch's repositories.
- Built with `makechrootpkg -c` in a clean chroot in the disposable
  development VM `rice-pkgs`; its `.BUILDINFO` records the sha256 of this
  PKGBUILD, and the archive holds `/usr/bin/hyprshade`, the Python package,
  the shaders `blue-light-filter.glsl` and `vibrance.glsl` under
  `/usr/share/hyprshade/shaders`, the example config, shell completions and
  the license. No file is setuid or group-writable.
- Release VM, 2026-09-30 (fix proof p10): installed with `pacman -U`; degra02
  (`hyprshade on vibrance`), which had stopped at hyprshade and pyprland,
  fetched complete and switched there and back.
