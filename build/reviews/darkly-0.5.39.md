# darkly 0.5.39-2, x86_64

- Provenance:
  - Upstream tag `v0.5.39` is a lightweight tag on
    `65f6fa62675e3c30986f8fc8e4fdbba053096491`, made in GitHub's web
    interface; its GitHub signature verifies.
  - The tag moved once: it first pointed at `286498e`, whose CI run (#35)
    failed, then at `65f6fa6` (run #36). The only difference is the VERSION
    file.
  - The recipe's sha256 equals the download and `git archive 65f6fa6`.
- The local PKGBUILD is the AUR recipe `darkly` at `204aad8` (generated by
  DeltaCopy/darkly-aur-ci, whose checksums are whatever GitHub served) with
  `provides=('darkly-bin')` and `conflicts=('darkly-bin')` added:
  caelestia's manifest names `darkly-bin`, the prebuilt package of the same
  release. Larch builds it from the tagged source instead of taking that
  binary. The Qt6/KF6 half only (`BUILD_QT5=OFF`), as in the AUR recipe.
- For comparison, darkly-bin's asset is upstream's own CI build of
  `65f6fa6`: its recorded PKGBUILD checksum was reproduced from the in-repo
  PKGBUILD, and all 46 embedded `file:line` markers hit `65f6fa6`. It is not
  used.
- Nothing is downloaded beyond the tarball (no FetchContent,
  ExternalProject or translation fetching).
- What the Qt style does beyond painting: no process execution, network,
  library loading or file writes in `kstyle/`, `kdecoration/` or
  `libdarklycommon/` (grep over about 30,000 lines; the v0.5.38 to v0.5.39
  diff was read in full: 8 files, painting and config).
  - It reads `darklyrc` and `kdeglobals` and listens for the D-Bus signal
    `org.kde.Darkly.Style.reparseConfiguration`.
  - It installs application-wide event filters for Alt mnemonics and window
    dragging, and sets blur regions.
  - Only its settings dialogs write `~/.config/darklyrc` and send D-Bus
    signals.
  - The theme SVGs contain no scripts.
- Built with `makechrootpkg -c` in a clean chroot in the disposable
  development VM `rice-pkgs`; the archive's `.BUILDINFO` records the sha256
  of this PKGBUILD. The file list matches the recipe: the Qt6 style plugin,
  the KDecoration3 plugin and its KCM, the style config plugin,
  `darkly-settings6`, two desktop files, a KService file, the `Darkly` color
  scheme, icons, kstyle themes and a Plasma desktop theme. Every linked
  library comes from the declared KF6/Qt6 dependencies or theirs. No file is
  setuid or group-writable.
- Release VM, 2026-09-30: installed with `pacman -U` beside the other eight
  packages of this set and caelestia's six, without conflict; no Qt Widgets
  application loaded the style in that test.
- License: mixed. 83 files GPL-2.0-or-later, 29 MIT (from Oxygen), 7 with
  KDE's GPL-2/3 wording, 6 without a header; the recipe declares
  GPL-2.0-or-later and the package installs no license file, so the MIT
  notice is not shipped.

  This approval covers no other version, architecture, or build.
